# ReyTraced Portfolio

A responsive personal portfolio website for **Justine Rey I. Garcia**, built with semantic HTML and Tailwind CSS.

## Overview

The website presents:

- A personal introduction and profile section
- About and educational background
- Technical and design skills
- Featured projects
- Achievements and certifications
- Contact information and a message form

## Built With

- HTML5
- Tailwind CSS via CDN
- Google Fonts
- Responsive design utilities

## Getting Started

No build tools or package installation are required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

You can also serve the project locally with any static file server, for example:

```bash
python -m http.server
```

Then visit `http://localhost:8000` in your browser.

## Project Structure

```text
.
├── index.html   # Main portfolio webpage
└── README.md    # Project documentation
```

## Customization

To personalize the portfolio, edit `index.html` to update:

- Profile information
- Skills and proficiency levels
- Education history
- Project descriptions and images
- Contact details
- Colors, typography, and layout

The page currently loads Tailwind CSS and external images/fonts from CDNs, so an internet connection may be required for the complete styling and media experience.
